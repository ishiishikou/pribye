# Security Policy

## Reporting a vulnerability

Do not include credentials, private keys, certificates, provisioning profiles, API keys, personal data, school print images, or OCR content in a public issue or pull request.

Use GitHub private vulnerability reporting when it is available. Otherwise, contact the repository owner through the GitHub profile without attaching secret values or personal data.

If a credential may have been exposed, revoke or rotate it first, then report the affected component, commit, workflow run, and exposure window.

## Supported version

Security fixes are applied to the current `main` branch. No support policy is provided for older commits or TestFlight builds.
